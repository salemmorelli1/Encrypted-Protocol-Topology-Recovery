Authorized acquisition

Fields, not frames.

Scapy or TShark receives packets from one named local interface. The adapter extracts six permitted metadata fields and discards each packet object; no PCAP is written.

Operator requirement
Use only your own computer/interface or one you are expressly authorized to monitor. The command refuses to run without --authorized-capture.

Measure-correct inference

The compensator stays in.

The event log-intensity is only half the likelihood. The exact observation-window compensator normalizes the continuous-time point process; the flow Jacobian likewise remains inside the variational density.
